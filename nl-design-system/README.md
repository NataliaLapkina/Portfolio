# NL Design System

Дизайн-система бренда **Natalia Lapkina — AI & Digital Products**.

Фундамент для всех будущих проектов: лендинги, портфолио, SaaS, дашборды.  
На текущем этапе — только структура библиотеки; существующий сайт Portfolio не затрагивается.

---

## Структура

### `css/`

Базовые стили дизайн-системы (подключаются в будущих проектах, не в текущем Portfolio).

| Файл | Назначение |
|------|------------|
| `variables.css` | Design tokens: цвета, типографика, отступы, радиусы, тени, easing |
| `reset.css` | Нормализация и сброс браузерных стилей |
| `typography.css` | Шрифты, scale, заголовки, body-текст, editorial-иерархия |
| `layout.css` | Сетка, контейнеры, секции, spacing-система |
| `components.css` | Стили UI-компонентов (будут добавляться по мере разработки) |
| `animations.css` | Keyframes, motion tokens, reveal и micro-interactions |
| `responsive.css` | Breakpoints и адаптивные правила |

### `js/`

Поведение интерфейса без привязки к конкретному проекту.

| Файл | Назначение |
|------|------------|
| `navigation.js` | Навигация, мобильное меню, scroll-spy |
| `animations.js` | Scroll reveal, stagger, reduced-motion |

### `patterns/`

Готовые HTML/CSS-паттерны по категориям (заготовки папок для будущих блоков).

| Папка | Назначение |
|-------|------------|
| `buttons/` | Кнопки и CTA-варианты |
| `cards/` | Карточки продуктов, кейсов, услуг |
| `hero/` | Hero-секции и product landing |
| `navbar/` | Шапка и навигация |
| `footer/` | Подвал сайта |
| `forms/` | Формы и поля ввода |
| `faq/` | Блоки вопросов и ответов |
| `pricing/` | Тарифы и pricing tables |
| `timeline/` | Временные шкалы и процессы |
| `cta/` | Призывы к действию |
| `sections/` | Составные секции страниц |

### `templates/`

Шаблоны целых типов страниц.

| Папка | Назначение |
|-------|------------|
| `landing/` | Маркетинговые лендинги |
| `portfolio/` | Портфолио и case studies |
| `dashboard/` | Панели управления и админки |
| `saas/` | SaaS-продукты и продуктовые страницы |

### `assets/`

Статические ресурсы дизайн-системы.

| Папка | Назначение |
|-------|------------|
| `icons/` | Иконки (SVG и наборы) |
| `illustrations/` | Иллюстрации и декоративная графика |
| `mockups/` | Мокапы интерфейсов для превью |

### `docs/`

Документация для команды и AI-ассистентов.

| Файл | Назначение |
|------|------------|
| `Design-Principles.md` | Принципы бренда и визуального языка |
| `Components.md` | Реестр компонентов и статусы |
| `Changelog.md` | История изменений дизайн-системы |
| `Roadmap.md` | План развития и приоритеты |

### `cursor/`

Правила и промпты для работы в Cursor.

| Файл | Назначение |
|------|------------|
| `system-prompt.md` | Контекст бренда и DS для агента |
| `coding-rules.md` | Стандарты вёрстки и именования |
| `component-template.md` | Шаблон описания нового компонента |
